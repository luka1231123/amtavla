[2026-04-11 20:44:31.980] TURN 11 ASSISTANT
[2026-04-11 20:44:31.980]   - **Recursion** is a programming technique where a function calls itself to solve smaller instances of the same problem.
[2026-04-11 20:44:31.980]   - **Base Case**: This is the simplest case where the function can return a result without further recursion.
[2026-04-11 20:44:31.980]   - **Recursive Case**: The function calls itself with a modified argument, breaking down the problem into smaller parts.
[2026-04-11 20:44:31.980]   - **Example**: Calculating the factorial of a number `n`:
[2026-04-11 20:44:31.980]     ```python
[2026-04-11 20:44:31.980]     def factorial(n):
[2026-04-11 20:44:31.980]         if n == 0:  # Base case
[2026-04-11 20:44:31.980]             return 1
[2026-04-11 20:44:31.980]         else:  # Recursive case
[2026-04-11 20:44:31.980]             return n * factorial(n - 1)
[2026-04-11 20:44:31.980]     ```
[2026-04-11 20:44:31.980]   - **Key Points**: Recursive functions must have a base case to terminate and a recursive case to progress towards the base case.
