[2026-04-11 19:09:37.807]   
[2026-04-11 19:09:37.807]   1. **Function Call**: The function calls itself.
[2026-04-11 19:09:37.807]   2. **Base Case**: This is a condition that stops the recursion. Without a base case, the function would call itself indefinitely.
[2026-04-11 19:09:37.807]   3. **Recursive Case**: This is where the function calls itself with a smaller or simpler version of the problem.
[2026-04-11 19:09:37.807]   
[2026-04-11 19:09:37.807]   Example: Calculating the factorial of a number.
[2026-04-11 19:09:37.807]   
[2026-04-11 19:09:37.807]   ```python
[2026-04-11 19:09:37.807]   def factorial(n):
[2026-04-11 19:09:37.807]       # Base case: if n is 0 or 1, return 1
[2026-04-11 19:09:37.807]       if n == 0 or n == 1:
[2026-04-11 19:09:37.807]           return 1
[2026-04-11 19:09:37.807]       # Recursive case: n * factorial of (n-1)
[2026-04-11 19:09:37.807]       else:
[2026-04-11 19:09:37.807]           return n * factorial(n-1)
[2026-04-11 19:09:37.807]   ```
